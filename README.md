# ELMansy PS4 HOST

A lightweight, static Arabic/English firmware information page with a royal Egyptian black-and-gold theme.

## Publish with GitHub Pages

1. Create a new repository on GitHub (for example: `elm ansy-ps4-host` without spaces, such as `elm ansy-ps4-host` -> `elmansy-ps4-host`).
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish the site; the URL will appear in the Pages settings.

## Notes

- This is an informational static site. It does not run exploits, payloads, or executable files.
- A normal webpage cannot reliably read the PS4 system firmware version. The current version selector is manual.
- Do not assume nearby firmware versions share the same compatibility method. Add only verified, version-specific information from trusted documentation.
- `assets/royal-concept.png` is an optional design reference image and is not required for the page to work.
