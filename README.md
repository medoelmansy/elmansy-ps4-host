# ELMansy PS4 HOST — Royal Edition

Updated static Arabic/English GitHub Pages site with a black-and-gold Egyptian visual theme, responsive layout, and a firmware version selector.

## Update the existing GitHub repository
1. Open `https://github.com/medoelmansy/elmansy-ps4-host`.
2. Upload and replace `index.html`, `style.css`, and `script.js` in the repository root.
3. Upload the complete `assets` folder, including `royal-egyptian-bg.webp`.
4. Commit the changes to `main`.
5. Wait a few minutes, then refresh the live site. If the old version remains, clear the browser cache or open a private tab.

This is an informational page. It does not execute exploits or payloads. The firmware selector is manual because a webpage cannot reliably read the PS4 system firmware from the browser.
